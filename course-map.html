        Setting it up

        Building it in Skool.

        1. Add every courseClassroom, then Add course, in the order above. Paste the description, add a cover, set access to All members and publish it.
        2. Add every lessonAdd a page per lesson with the exact title. Put 🔒 at the start of any lesson you haven't filmed.
        3. Keep them publishedDraft pages are hidden from members. Published placeholders let people see the whole course.
        4. Swap in the videoWhen one's filmed: add the video, remove the 🔒, replace the text and post in the group that it's live.

        Courses that aren't out yet: start the description with the opening date so it shows on the course card. If the group is paid, non-members can't see the classroom, so post the free A to Z somewhere public as well and link to it.
