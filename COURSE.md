## Setting it up in Skool

1. **Classroom → Add course** for each course below, in this order. Paste the
   course description, add a cover image, set access to **All members** and
   **Published**.
2. Inside each course, **add a page** for every lesson (use **sets** if you want
   to group them). Use the exact lesson title.
3. For lessons not filmed yet, start the title with 🔒 and paste the placeholder
   text below into the page. Keep the page **published**: draft pages are hidden
   from members, which hides the structure you want them to see.
4. When a lesson is ready: add the video and resources, remove the 🔒, replace the
   placeholder text, and post in the community that it's live.

Courses that aren't out yet: put the opening date at the start of the description
(e.g. "Opens Monday 26 October") so it shows on the course card. Skool's **Time
unlock** option can lock a whole course for X days after someone joins, but that
counts from each member's join date, so it only lines up for people who join on
launch day - the placeholders are simpler and let people look inside.

If the group is paid, non-members can't see the classroom, so post the free A to Z
somewhere public too (unlisted YouTube or the waitlist page) and link it.
